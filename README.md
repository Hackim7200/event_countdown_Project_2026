## Event Countdown

Full-stack project with AWS CDK infrastructure and a Flutter client using
Amplify.

## Structure

- `cdk_infrastructure/` AWS CDK stacks and Lambda handlers
- `event_countdown/` Flutter app (Amplify client setup)

## Prerequisites

- Node.js + npm (for CDK)
- AWS CLI configured for your account
- Flutter SDK (for the client)

## Quick start

1. Review `cdk_infrastructure/` for infrastructure setup and deployment.
2. Open `event_countdown/` for the Flutter client.

## Notes

- The Flutter app README lives at `event_countdown/README.md`.
- CDK outputs are stored in `cdk_infrastructure/outputs.json` when deployed.
